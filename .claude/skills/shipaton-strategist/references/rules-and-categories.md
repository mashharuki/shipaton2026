## 参加要件（失格を避けるための必須事項）

1. **新規アプリであること**: iOS / iPadOS / macOS / Android 向け。初回公開が提出期間内（8/1〜9/30）であること。**既存アプリのアップデートは対象外**
2. **RevenueCat SDK の統合**: 概要ページの表現には揺れがある。
   - Challenge欄: 「RevenueCat SDKで購入を処理する、または RevenueCat Ads で広告を配信する」
   - Requirements欄: 「RevenueCat SDKで少なくとも1つのアプリ内購入またはWeb購入を処理する」
   
   広告のみで収益化する場合（特に **Catvertising Award** 狙い）でも、この表現の揺れにより購入導線なしで通常応募の要件を満たせるかが不確定。**正式規約公開までは、広告のみに頼らず最低1つの購入導線も実装しておくのが安全策。**
3. **ストア公開**: App Store / Google Play / Samsung Galaxy Store のいずれかに公開済みであること。**Next Gen Award の学生は例外**で、公開ストアURLの代わりに動画とオープンソースコードでの応募が認められる
4. 参加者は居住国の成年年齢以上であること（一部の国・地域は除外）

## 賞カテゴリ: RevenueCat主催9つ＋スポンサー賞7つ＋インフルエンサー賞5つ＝合計21カテゴリ

以下はRevenueCat主催の9カテゴリ。**スポンサー賞（JetBrains/Noise/Replit/OneSignal/Layers/Stripe/Samsung）とインフルエンサー賞（Productivity/Nutrition/Yoga & Fitness/Career Coaching/Gaming の5部門）は `references/sponsor-and-influencer-awards.md` に詳細をまとめてある。** 特にインフルエンサー賞は審査員個人が公言している「欲しいアプリ像」がそのまま基準になっており的を絞りやすいため、ユーザーの経験がこれらのニッチに近い場合は必ず案内すること。

### 1. Grand Prize（1位 $100,000 / 2位 $20,000 / 3位 $10,000）

必ずしも「技術的に最も高度」「デザインが最も美しい」アプリに与えられるわけではない。中心となる評価軸はイベント期間中の実績:

- ユーザー数の伸び、ダウンロード数や登録数
- 有料ユーザーの獲得、売上やトランザクションの増加
- リリース後に行った成長施策と、期間中の成長速度・勢い
- ユーザーの反応をもとにした改善

**狙い方**: 「作って終わり」ではなく「作って、出して、伸ばす」ところまでが審査対象。8月上旬に早期リリースし、9月をまるごとグロース期間に充てる。「初週50人→改善後500人」「ペイウォール変更で購入率2%→6%」のような**成長ストーリー**をDevpostの説明文で明示できると強い。難易度は最高で、完成度だけでは獲れない。

副賞にはニューヨークのShippies授賞式・App Growth Annualへの**1名分の渡航**が明記されている（他カテゴリとの違いは後述「1位特典の違い」参照）。

## 賞金総額の内訳と数値の整合性

ユーザー提供資料に基づく積み上げ:

| 区分 | 賞金構成 | 合計 |
|---|---|---|
| Grand Prize | $100,000（1位のみ集計） | $100,000 |
| #BuildInPublic | $30,000 / $20,000 / $10,000 | $60,000 |
| OneSignal（Keep Them Coming Back） | $25,000 / $15,000 / $5,000 | $45,000 |
| その他16部門（RCカテゴリ賞6＋スポンサー賞5＋インフルエンサー賞5） | 各 $15,000 / $10,000 / $5,000 | $480,000 |
| **合計** | | **$685,000** |

この積み上げは公式表示の **$685,000+** と完全に一致する。一方、Devpost概要ページを直接確認した際の記録では Grand Prize は「1位 $100,000 / 2位 $20,000 / 3位 $10,000」（3賞合計$130,000）と明記されており、これをそのまま合計に含めると総額は $715,000 になり公式表示と食い違う。

**したがって「Grand Prizeに2位・3位の賞金が実在するか」は情報源によって食い違っており未確定。** 提出前に公式ページで最終確認すること。Samsung・Conflict of Interest の2部門は現金賞が明記されていないため、いずれの積み上げにも含めていない。

マーケティング文言の「$1,000,000+相当」は、上記の現金賞に加えて旅費・ビルボード掲載・Ship Kit特典等の非現金価値を加算したものとみられる。

## 1位特典の違い（渡航費の扱いに注意）

Grand Prize と #BuildInPublic Award の1位には、明確に**「Travel for one」（1名分の渡航）**が記載されている（ニューヨークのShippies授賞式・App Growth Annualへ）。

一方、その他多くのカテゴリーの1位は英語表記で

> Invitation to RevenueCat's App Growth Annual conference

となっており、これは「カンファレンスへの招待」を意味するのみで、航空券・ホテル等の渡航費がすべて含まれるとは限らない。Grand Prize / #BuildInPublic の「Travel for one」とは表現が異なるため、**渡航費の扱いは公式ルールで必ず確認する**よう案内すること。

## 一般的な審査観点（全カテゴリ共通の土台）

- **Innovation**: 市場に対する新規性（新しいアイディア・機能・ユースケース）
- **Execution**: 実装の完成度・安定性・視覚的一貫性
- **Feasibility**: ハッカソン後も現実的に成長・継続できるか
- **Integration**: RevenueCat SDK / API の効果的な活用

## カテゴリ選定の指針

1. **主軸1つ＋副次1〜2つ**を選ぶ。全方位狙いは全敗する
2. 主軸はユーザーの強み（デザイン力・マネタイズ思想・当事者性・発信力）と一致させる
3. #BuildInPublic は常に副次として乗せる（賞金額も他カテゴリ賞より高く、相乗りコストが低い）
4. グランドプライズは「結果として獲れたら嬉しい」位置付けにし、設計段階ではカテゴリ賞に最適化する方が期待値が高い
5. スポンサー賞・インフルエンサー賞（`references/sponsor-and-influencer-awards.md`）は、RevenueCat主催の9カテゴリより認知度が低く応募数が少ない可能性が高いため、コンセプトが合致するなら積極的に主軸/副次として組み込む

### 組み合わせの具体例

アプリのコンセプトに応じて、次のような3〜5部門の組み合わせが考えられる（スポンサーSDKを目的なく大量に入れるのではなく、**アプリの中心的なユーザー体験と自然につながるカテゴリー**を選ぶこと）:

- **AIコーチング/対話系アプリ**: Career Coaching（インフルエンサー賞）+ HAMM Award + OneSignal + #BuildInPublic + Grand Prize + RevenueCat Design Award
- **ゲーム**: Best Game + Gaming（インフルエンサー賞）+ Catvertising + Most Viral App（Noise）+ OneSignal + Grand Prize
- **Kotlin Multiplatform / Compose Multiplatform アプリ**: Ship Kotlin Everywhere（JetBrains）+ HAMM Award + RevenueCat Design Award + #BuildInPublic + Grand Prize

## 日本からの参加動向と戦略的示唆（2026年7月時点）

出典: ユーザー共有のX投稿（開始1ヶ月前の事前登録データ、一次ソース未確認のため参考情報として扱う。数字の断定はせず、時流の把握に使うこと）

- 日本からの登録数がグローバル全体の**半数以上**を占めている（事前登録の時点で計測）
- 2025年は開催期間を通じて日本からの参加者は約240名。2026年はすでにその**約5倍**に達している（しかも開始1ヶ月前の時点）

**この統計が示す戦略的含意**:
- 日本語圏コミュニティでの参加規模が前回比で大きく拡大しているため、**定番テーマ（習慣化アプリ・家計簿・日記・単純なポモドーロ等）は同時多発的にかぶりやすい**。Phase 2 のアイディア出しでは「本人が語れる本物の課題」の掘り起こしと差別化ポイントの明確化を、例年以上に重視すること
- 一方でグローバル審査という土俵では、日本語ローカライズやニッチな日本文化文脈に根ざしたテーマは差別化要因にもなり得る（審査員に伝わるよう英語のピッチ・デモ動画での説明を丁寧に作ることとセットで）
- #BuildInPublic は日本語コミュニティでの発信だけでなく、英語圏（X等）での発信も並行するとグランプリ/#BuildInPublic Award 双方への相乗効果が期待できる

## 複数アプリ提出・複数受賞の扱い（要確認事項）

昨年（2025年）は1人が複数アプリを提出することが可能だった。2026年に同じルールが継続されるかは本稿執筆時点で不明。複数アプリ提出の可否や、1人・1チームが複数賞を受賞できるかの扱いは、**公式ルール（Official Rules）確定後に必ず確認する**よう、ユーザーが「並行して複数アイディアを進めたい」と言った際には案内すること。
